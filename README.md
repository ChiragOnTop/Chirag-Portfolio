# Chirag Gambhir — Futuristic AI Engineer Portfolio

A cinematic, Awwwards-level portfolio — holographic OS aesthetic with space intro, orbital skills, and featured AI/CV projects.

## Experience

1. **Cinematic intro** — solar system → Earth zoom → energy burst → particle name → profile reveal → OS boot
2. **Hero** — CHIRAG GAMBHIR, rotating roles, 3D particles, reactive HUD
3. **About** — storytelling pillars + animated stats
4. **Skills** — 3D orbital tech matrix (no progress bars)
5. **Projects** — Stellar AI, Air Canvas (featured) + additional work
6. **Experimental Labs** — innovation grid
7. **Contact** — sci-fi communication terminal

## Stack

React 19 · Vite 8 · Tailwind v4 · Three.js / R3F · GSAP · Framer Motion · Lenis

## Commands

```bash
npm install
npm run dev
npm run build
```

## Deploy on Vercel

1. Push this repo to GitHub: `https://github.com/ChiragOnTop/Chirag-Portfolio`
2. Go to [vercel.com/new](https://vercel.com/new) → Import **Chirag-Portfolio**
3. Framework: **Vite** (auto-detected)
4. Build command: `npm run build` · Output: `dist`
5. Deploy

`vercel.json` is included for SPA routing.

## Customize

- Content: `src/data/portfolio.js`
- Intro: `src/components/intro/`
- Re-watch intro: `sessionStorage.removeItem('intro-skipped')` then refresh
