# Chirag Gambhir — Futuristic AI Engineer Portfolio

A cinematic, Awwwards-inspired portfolio built with React, Vite, Tailwind CSS, Three.js, GSAP, Framer Motion, and Lenis smooth scrolling.

## Stack

- **React 19** + **Vite 8**
- **Tailwind CSS v4** — glassmorphism, holographic utilities
- **Three.js** + **React Three Fiber** — hero particle field & holographic torus
- **GSAP** + **ScrollTrigger** — scroll choreography & section reveals
- **Framer Motion** — micro-interactions & subtitle transitions
- **Lenis** — premium smooth scroll

## Sections

- Navbar (glass, responsive menu)
- Hero — CHIRAG GAMBHIR, rotating subtitles, 3D particles, interactive HUD
- About, Skills, Projects (horizontal scroll on desktop), Labs, Contact, Footer

## Commands

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
npm run preview
```

## Customize

Edit content in `src/data/portfolio.js` — projects, skills, labs, social links, and subtitles.
